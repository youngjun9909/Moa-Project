## 알려진 비차단 경고

- CRA 개발 서버가 테스트 파일 추가 이전의 모듈 해석 오류 오버레이를 캐시했으나, 오버레이를 닫은 실제 화면과 최신 프로덕션 빌드는 정상이다.
- React 18 테스트 유틸 deprecation, 일부 비동기 `act` 및 기존 hook dependency 경고가 남아 있다. 전체 테스트와 번들은 통과한다.
- 이번 화면 개편에서 API 계약은 변경하지 않았으므로 백엔드 테스트는 실행 대상에서 제외했다.
